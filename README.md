# SX Jewelry site

Static GitHub Pages site for `https://www.sx-jewelry.com/`.

## Current positioning

- Public brand: `SX Jewelry`
- Product focus: fashion jewelry, pet memorial keepsakes, gift packaging, wooden box combinations
- Sending email: `sales@sx-jewelry.com`
- Do not send outreach from this mailbox until SPF / DKIM / DMARC and basic warmup are done.
- This page does not certify compliance; it only says SX Jewelry can request material declarations and third-party lab reports on the buyer's behalf
- This page clearly says SX Jewelry does not handle pet ashes or hair

## Deployment files

- `index.html` - public landing page.
- `CNAME` - GitHub Pages custom domain.
- `robots.txt` - crawler access and sitemap reference.
- `sitemap.xml` - root URL sitemap.
- `8f2b9c7d4a6e4f2b8c1a0d9e7f3b5c6a.txt` - IndexNow key file.

## Pre-send check

1. Visit `https://www.sx-jewelry.com/`.
2. Search the live source and confirm there is no `placeholder` or `replace`.
3. Open `https://www.sx-jewelry.com/robots.txt`.
4. Open `https://www.sx-jewelry.com/sitemap.xml`.
5. Open the page on a mobile-width browser and confirm the first screen and table are readable.
